## 环境限制（下次直接复用结论，别重复探测）

- 这台机器**没有 `gh` CLI**，没有 `~/.git-credentials`、没有 `~/.netrc`、
  keychain 里也没有 GitHub 条目，全局没配 `credential.helper`。
- `~/.ssh/id_rsa` **没有注册到任何 GitHub 账号**（SSH 走 443 得到
  `Permission denied (publickey)`）。
- **github.com:22 SSH 被网络阻断**（连接超时）；`ssh.github.com:443` TCP 通，
  但公钥认证失败。
- HTTPS 通：`https://github.com` 200、`api.github.com` 403（可达）、
  `codeload.github.com` 301。
- 结论：要推 GitHub 只能走 **HTTPS + Personal Access Token**，且必须由用户提供
  token 与用户名/仓库名。
