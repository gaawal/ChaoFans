## GitHub 推送成功（最终解法，下次直接复用）

- 账户 **gaawal**，仓库 `git@github.com:gaawal/ChaoFans.git`（空仓库用户自建）。
- `~/.ssh/id_rsa.pub` 用户手动加到 GitHub；`~/.ssh/config` 已配
  `Host github.com → ssh.github.com:443 + ProxyCommand nc -X connect -x 127.0.0.1:7897`
  （本机 7897 是 Clash 代理；直连 22/443 都被重置）。
- **直推 main 必败**：首次提交含 ~137MB 二进制（两版 .blend 40/33MB、
  新旧 GLB、HDR、参考图），代理隧道 ~3 分钟被远端掐断（broken pipe）。
- **可行解法 = 分块推送**：给每个 >4MB 的 blob 建 annotated tag，
  逐个 `git push origin chunk-N`（压缩后 5-20MB/个，~1.7MB/s，单块几秒），
  全部上去后 `git push -u origin main`（大对象已在服务端，main 只传小文件），
  最后远端+本地删临时 tag。断线重试时如显示 "Everything up-to-date"
  说明上次其实已传完，用 `git ls-remote --tags` 验证即可。
- **后台任务（run_in_background）里 git push 会秒败**（access rights 报错，
  疑似沙箱无网络）——git 网络操作一律前台跑，长任务分批。
